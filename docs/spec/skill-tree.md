# セル種類別の共有スキル

タグ: `現行仕様` `PRG-03` `成長` `通貨` `種類別強化`

## 取得条件と効果

2026-11-09、ユーザーが1Aを採用した。従来の採取・搬送・保管の共通3系統と一基ずつの購入UIを、セル種類別のスキルへ統合する。一プレイで一つの取得状態を持ち、MainSceneの共有残高から購入する。取得状態と種類別レベルは再開始で初期化する。定義は[SkillTree.asset](../../Assets/Scripts/ScriptableObject/SkillTree.asset)に集約し、起動時に不変カタログへコピーする。

基礎研究は50で、5種類のIを解放する。各Iは50で同種セル全体をLv.1→2、各IIは100でLv.2→3へ上げる。IIの前提は同じ種類のI。価格は従来スキルの段階価格を初期値として引き継いだもので、種類別の価格は同じ定義内で編集できる。

| 固定uidの接頭辞 | 対象 | レベルが増やす能力 |
| --- | --- | --- |
| wood | 木材採取 | 抽出量、抽出在庫容量 |
| stone | 石材採取 | 抽出量、抽出在庫容量 |
| storage | 保管庫 | 容量 |
| crafter | 加工設備 | 入力方向ごとの容量、出力容量 |
| export | 搬出路 | 搬送量 |

各接頭辞に`-1`・`-2`を付けた10ノードと`basic-research`の計11ノードを使う。基礎値に種類別レベルを乗じ、Iで2倍、IIで3倍となる。既設・非アクティブ後の再有効化・新設セルへ同じ種類別レベルを適用する。他の種類のレベルは変えない。

通常搬送路は、現状の搬送量プロパティを実際の受領・中継に使わないため、今回の強化対象から外す。速度強化などの追加仕様は、後処理を優先するユーザー指示に従って保留する。通常搬送の数量・速度は現状を保つ。

空・資源・特異点は強化対象外。交差搬送路は上流から渡された固定数量をそのまま中継し、独立した搬送量を持たないため、効果のない強化ノードを追加しない。稼働中の抽出量・搬送数量・加工計画と、在庫・予約・位置・方向・接続・Identityは[有効能力仕様](effective-stats.md)に従って保持する。

## 表示と操作

左の樹形図でノードを選ぶと、右に対象種類、適用後のレベル・倍率、価格付きの「適用する」を表示する。選択だけでは支払わない。未解放は暗いグレー、解放済みの残高不足は通常色、選択は白枠、適用済みは記号で示す。種類別の枝はノード幅を保ち、樹形図内の横ドラッグとスクロールバーで移動できる。選択ノードを表示範囲へ寄せ、選択内容が同じ更新ではスクロール位置を保つ。

セルを選んだ右側の状態欄は、種類名・共有レベル・在庫・加工や停止状態の読み取り専用とする。個別の強化購入ボタンは表示しない。スキル間の選択は右枠を閉じ直さず、色を途中の通常色へ戻さず更新する。

残高不足と配置の重なりはUIへ表示する。生成・初期化・対象消失などシステム上の失敗はConsoleへ記録する。

## 定義と購入の検証

Domainは空定義、nullノード、空uid・名称、価格0以下、uid重複、前提欠落、自己参照・循環を拒否する。種類別効果は対象5種類、Lv.2・3、同一種類と段階の重複、種類別効果と旧加算率の混在を検証する。Lv.3は同じ種類のLv.2を前提にする。価格は正のlongで、既存の支出予約によって不足を判定する。

`SkillTreeApplication`は取得状態、購入可否、支出予約と確定を管理する。予約後に取得状態・前提・共有状態を再確認し、不成立なら予約を取り消す。取得状態と種類別レベルを通知せず更新してから支出を確定し、その後に共有能力とツリーを通知する。残高の確定通知から更新済みレベルを読める。通知中の再入と同じuidの二重支払を拒否し、通知先の例外は記録して残りの購読者へ通知する。

種類別レベルはグリッド所有の`SharedStatEffectsApplication`が保持する。セルの`ProgressionType`が同じ共有状態を読むため、一基ずつの更新・再生成・再初期化を行わない。旧加算率と個別レベルの低水準入口は能力計算・取引の既存回帰用に保持し、MainSceneの通常UIは種類別スキルだけを使う。

## 検証入口

[SkillTreeVerifierEditor.Run](../../Assets/Scripts/Progression/Editor/SkillTreeVerifierEditor.cs)は定義不正、前提、不足、重複、long境界、通知再入・例外、予約後の再確認を検証する。MainSceneで5種類の既設・非アクティブ・再有効化・新設セルへのI/II、他種類の不変、在庫・予約・Identity、稼働中の抽出・搬出・加工と交差の中継予約を確認する。

[EconomyUIVerifierEditor.RunRendered](../../Assets/Scripts/Economy/Editor/EconomyUIVerifierEditor.cs)はスキルの選択・適用、セル状態の読み取り専用化、横移動とPC2寸法を既存HUDと合わせて確認する。[EconomyLoopVerifierEditor.Run](../../Assets/Scripts/Economy/Editor/EconomyLoopVerifierEditor.cs)は実際の換金収益で全種類のI/IIを取得し、新設設備への継承と収支を照合する。実行条件・対象差分・ログ・代表画像はローカルの`docs/verification/type-skills.json`へ集約する。
